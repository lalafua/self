### 数据的表示与计算

[Q] 为什么 IEEE 754 要用移码表示指数部分，而不是原码或补码
[A] 
1. 补码不能按无符号二进制排序
2. 移码能避免符号位单独处理
3. 使用移码可以使得：1.浮点数比较大小时，只需按无符号数比较两个浮点数的位串；2.指数加减只需把移码转换回真值再操作，然后重新编码为移码；3.浮点排序算法可以直接用整数排序算法（如快排）处理底层二进制

[Q] IEEE 754 浮点数中，从非正规数（denormalized numbers）到正规数（normalized numbers）过渡时的一个关键点：为什么非规格化数（0.f）对应的移码（exponent）是 1-Bias，而不是 0-Bias？
[A] 为了在非常接近 0 的地方保持精度连续性
以单精度浮点数举例：

- 最小规格化数：
    - 指数 exp = 1
    - 尾数 frac = 0
    - 值为 $1.f * 2^{exp-bias} = 1.0 * 2^{1-127}$
- 最大非规格数：
    - 指数 exp = 0
    - 尾数 frac = 111……1 (32-1-8 = 23 个 1)
    - 值为 $0.f * 2^{1-bias} = (1-2^{-23})*2^{1-127}$

发现非规格区指数固定是 -126，和最小规格化数的指数相同，这样两个区域无缝衔接，值不会跳跃

[Q] 虚拟内存设计的核心动机 
[A] 
| 问题         | 虚拟内存如何解决                                      |
| ---------- | --------------------------------------------- |
| 程序太大，装不下内存 | 分页存储，只把活跃部分（Working Set）放进物理内存，其他存在磁盘 |
| 多进程互不干扰    | 每个进程有自己的虚拟地址空间                                |
| 地址冲突       | 操作系统通过页表映射虚拟地址到不同的物理地址                        |
| 数据安全       | 用户进程访问非法地址会触发页错误（Page Fault）                  |
| 地址重定位      | 不需要程序知道其运行在物理内存的哪个位置                          |
